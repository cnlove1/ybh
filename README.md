# 图形大战（YBH）

一个基于 Next.js 16、React 19、TypeScript 和 Canvas 的浏览器小游戏，包含几何生存、数学挑战、金币换肤、成就图鉴和开发者模式。界面语言为简体中文，默认地址为 **http://localhost:5001**。

核心游戏不需要数据库、账号、API Key 或外部服务。金币、皮肤和成就保存在当前浏览器中。

## 快速启动

安装兼容版本的 Node.js 和 pnpm 后，在终端执行：

```bash
git clone https://github.com/cnlove1/ybh.git
cd ybh
pnpm install --frozen-lockfile
pnpm dev
```

打开 http://localhost:5001。保持终端运行；退出服务按 `Ctrl+C`。

仓库如果是私有仓库，需要先让 Git 获得该仓库的访问权限。不要将访问令牌写入远端 URL、README、环境示例或源码。

如果下载的是 ZIP：解压后进入含有 `package.json` 的 `ybh` 目录，再执行最后两条命令。**不要直接双击 HTML 文件**，本项目需要 Node 服务。

## 运行环境和安装

### 1. 安装 Node.js

- 最低版本：**Node.js 20.9.0**（来自项目使用的 Next.js 16.1.1 的 engines 要求）。
- 可使用兼容的较新 Node.js 版本；本版本已在 Node.js 24.22.1 上验证。
- 系统：Windows、macOS、Linux。启动、构建和生产运行使用 Node 脚本，不依赖 Bash、`ss` 或 GNU grep。
- 首次安装依赖需要可访问 npm 软件包注册表。

安装完成后，在新终端验证：

```bash
node --version
npm --version
```

如果仍显示旧版本，检查终端 PATH，关闭旧终端后重开。

### 2. 安装指定版本 pnpm

项目声明 `pnpm@9.0.0`。为保证锁文件和 overrides 的兼容性，使用该版本：

```bash
npm install --global pnpm@9.0.0
pnpm --version
```

没有全局安装权限时，可以使用：

```bash
npx --yes pnpm@9.0.0 install --frozen-lockfile
npx --yes pnpm@9.0.0 dev
```

不要混用 npm/yarn 安装项目依赖。保留仓库内的 `pnpm-lock.yaml`，不要为了安装失败随意删除它。

### 3. 安装并启动

```bash
cd ybh
pnpm install --frozen-lockfile
pnpm dev
```

浏览器第一次打开时 Next.js 会编译页面，稍等编译完成即可。开发模式中修改文件会自动更新页面；修改 `next.config.ts` 后应重新启动服务。

## 正式部署

### 本机或 Linux/Windows/macOS 服务器

在项目目录执行：

```bash
pnpm install --frozen-lockfile
pnpm ts-check
pnpm test:monkey
pnpm build
pnpm start
```

- `pnpm build` 先检查外部地址使用方式，再执行 Next.js 生产构建。
- `pnpm start` 使用已有构建启动生产服务，默认仍是 5001 端口。
- 源码或构建时配置变化后，必须重新 `pnpm build` 再启动。
- 构建不会自动安装依赖，因此部署前需先执行安装命令。
- 执行构建和启动时应使用相同的源码、Node 环境与构建输出目录。

部署到公网时，需要服务器开放所选端口，或通过反向代理将域名流量转到该端口。配置 HTTPS、域名和进程托管应遵循你所用主机的方式；仅在终端运行服务，关闭终端通常也会停止服务。

### 部署到支持 Next.js 的托管环境

使用支持 **Node.js 服务端运行时**的 Next.js 部署环境：

| 配置项 | 值 |
| --- | --- |
| 项目根目录 | 含有 `package.json` 的目录 |
| Node 版本 | 至少 20.9，建议与本地验证版本一致 |
| 安装命令 | `pnpm install --frozen-lockfile` |
| 构建命令 | `pnpm build` |
| 通用 Node 启动命令 | `pnpm start` |
| 端口 | 接受平台注入的 `PORT`，未设置时为 5001 |

某些平台由其 Next.js 适配器管理运行过程，此时按平台的适配器设置启动方式。不要将本仓库当作纯静态 HTML 上传至 GitHub Pages：项目包含 `/api/watermark` 动态接口，当前没有配置静态导出。

### 同时保留开发服务与生产验证

默认开发和构建都使用 `.next`。如果开发服务仍运行，生产验证请指定另一个输出目录，避免彼此覆盖。

macOS / Linux：

```bash
YBH_DIST_DIR=.next-release pnpm build
YBH_DIST_DIR=.next-release PORT=5002 pnpm start
```

Windows PowerShell：

```powershell
$env:YBH_DIST_DIR = '.next-release'
pnpm build
$env:PORT = '5002'
pnpm start
```

这时访问 http://localhost:5002。测试结束后可关闭进程；该输出目录已被 Git 忽略。

## 端口与环境变量

无需创建 `.env` 也能运行。可按需要复制 `.env.example` 为 `.env.local`，填写可选的服务配置；真实凭据不应提交到 GitHub。

**端口由启动脚本读取系统环境变量**，请在运行命令前设置，不要只把端口写进 `.env.local`。

macOS / Linux：

```bash
PORT=5002 pnpm dev
PORT=5002 pnpm start
```

Windows PowerShell：

```powershell
$env:PORT = '5002'
pnpm dev
```

Windows CMD：

```bat
set PORT=5002
pnpm dev
```

| 变量 | 用途 |
| --- | --- |
| `PORT` | 服务监听端口，默认 5001 |
| `USER_PROJECT_PORT` | 工作环境端口覆盖值，优先于 `PORT` |
| `DEPLOY_RUN_PORT` | 只对生产启动生效，优先级最高 |
| `WORKSPACE_PATH` | 可选的运行项目目录，通常无需设置 |
| `YBH_DIST_DIR` | Next.js 输出目录，默认 `.next`；构建和启动需保持一致 |
| `APP_EXTERNAL_ORIGIN` | 可选的外部访问根地址，用于外部 URL 解析 |
| `TUYA_OPEN_API_BASE_URL` | 可选的涂鸦水印权限服务地址 |
| `TUYA_OPEN_API_AUTH_KEY` | 该可选权限服务的服务端令牌，勿放进 `NEXT_PUBLIC_*` 变量 |
| `REGION` | `AY` 时水印链接使用国内地址，其他值使用国际地址 |

没有水印权限服务配置时，游戏可以正常游玩，默认展示平台水印。

## 游戏操作

进入主页后选择游戏模式。游戏中自动进行近战和远程攻击。

| 操作 | 作用 |
| --- | --- |
| `W A S D` / 方向键 | 移动角色 |
| `空格` | 切换停止/恢复近战及发射子弹；移动和敌人行为继续，已发射子弹仍会飞行 |
| `1` | 切换暂停/继续整局游戏；画面显示暂停提示 |
| 数学输入框中的 `1` | 输入答案数字，不触发暂停 |
| `Enter` / 确认按钮 | 提交数学答案 |
| 返回首页 | 结束当前一局，回到主菜单 |
| 重新开始 | 从本局初始属性重新开始，数学特殊模式仍保留 |
| 主页音效按钮 | 切换音效设置 |
| 游戏说明 | 查看游戏内规则 |

整局暂停时不能移动、攻击、拾取，也不能输入或提交数学答案。按住暂停键不会不断切换；Ctrl/Command/Alt 等组合快捷键不会误触游戏控制。切出窗口会清除已按下的移动键。

如果数学输入框正在输入答案，先点击输入框之外，再使用数字 `1` 暂停。游戏暂停后输入框和确认按钮会禁用。

## 几何模式与升级

初始生命值 1000，基础移动速度 120，基础攻击伤害 20。靠近敌人会自动近战；较远且在射程内的敌人会被自动射击。击杀怪物掉落绿色晶核，靠近后拾取。每累计 **20 个晶核**可选择一次强化，选择期间游戏暂停。

| 强化 | 效果 |
| --- | --- |
| 生命强化 | 最大生命值 +200，同时恢复200生命（不超过新的最大值） |
| 速度强化 | 每次增加原始移动速度的50个百分点，普通强化上限300%；达到上限后仍可选择以触发成就 |
| 暴击精通（概率未满） | 暴击概率每次 +10 个百分点，上限 **100%** |
| 暴击精通（概率已满） | 暴击伤害倍率每次 +5 个百分点；例如150%→155% |
| 多重射击 | 子弹数量 +1，最多5颗 |
| 穿透弹头 | 穿透数量 +1，最多穿透8个怪物 |
| 磁场强化 | 收集范围每次 +50 个百分点，上限200% |

**区分暴击概率和暴击倍率：**概率100%意味着每次攻击都暴击；伤害倍率1000%意味着暴击时造成基础伤害的10倍。本版本暴击伤害倍率没有硬上限，1000%是“秒天秒地”的成就门槛，不是倍率上限。起始伤害倍率为150%。

## 数学模式

输入屏幕上的算式答案，点击确认或按回车。答案必须是完整整数；错误内容、空输入和超出安全整数范围的数字不作为有效答题处理。同一题快速重复提交只处理一次。

| 规则 | 普通模式 | 特殊模式 |
| --- | --- | --- |
| 答对时攻击倍率增加 | `0.10 + 本次连胜数 × 0.05` | `0.20 + 本次连胜数 × 0.10` |
| 答错 | 连胜归零，攻击倍率保持 | 连胜归零，攻击倍率降为0.5 |
| 怪物每秒强化 | 当前属性倍率 ×1.01 | 当前属性倍率 ×1.02 |

例如普通模式第一次答对，攻击倍率从1.00变为1.15。连胜越高，后续题目越难，题目包含加减乘除，除法题保证整除。

当当前攻击力超过100后，每次答对额外增加10%攻速；重新开始一局会重置攻击与攻速加成。数学模式不掉落晶核（包括开发者模式），但仍有金币。

错题会记录在主页的“错题本”中，在当前页面会话内保留；重开不会清空，可手动点击清空按钮。**错题本没有持久化，刷新或关闭页面会丢失。**可打开草稿纸进行辅助计算。

## 怪物与难度

- 普通怪物分为1～5阶，另有6阶BOSS；敌人在屏幕外生成。
- 一般每2秒尝试生成怪物；每分钟有波次，首波10只，后续每波多5只，场上数量受30只上限约束。
- 波次有5%概率触发BOSS；出现时清除现有怪物。
- 几何模式每选择一次升级，怪物强化倍率增长30%。
- 所有模式怪物整体强化上限为 **1000%（原始属性的10倍）**，达到后不再继续强化。
- 怪物移动速度另受 **原始速度200%** 上限限制，包括BOSS召唤物。
- BOSS初始生命值为四阶怪基础生命值的5倍，再乘整体难度倍率；攻击伤害固定100，不随强化增加。首次5秒后召唤5只三阶怪，此后每10秒召唤一次，仍遵守数量上限。
- 本次同步保留了远端的怪物基础速度提升50%、击退力度减半及屏幕外生成改进。

## 金币换肤与存档

- 每个被击杀怪物有 **50%概率掉落1枚金币**，两种模式规则一致。
- 金币落地后需靠近拾取；30秒后消失。晶核15秒后消失。
- 主页点击“换肤”，每次花费 **10金币**，按顺序切换为不同皮肤。
- 皮肤共5种：黄金之光、冰霜之心、紫晶幻影、翡翠星辰、烈焰之魂。可以预览下一款，金币不足时不能购买。
- 金币、皮肤及成就通过浏览器 `localStorage` 保存；当前一局的生命值、强化、暂停状态和数学连胜不保存。

### 重置

主页“重置金币与成就”按钮会立即把金币归零、清除已有成就，再获得 **LET'S PLAY AGAIN** 成就。**该按钮不会恢复被清除的记录，请确认自己确实要重置后再点击。**当前皮肤保留。

### 存档范围

`localhost`、`127.0.0.1`、不同端口或不同域名属于不同来源，不共享存档。不同浏览器和隐私模式也不保证共享。清理网站数据会删除存档；没有跨设备账号同步。

存储键为 `ybh-appearance`（金币和皮肤）、`ybh-achievements`（成就ID数组）。浏览器禁止存储时可继续本次会话，但刷新后不保证保留。

## 成就图鉴

主页始终显示图鉴入口，列出全部成就、条件及已/未解锁状态。

| 成就 | 实际触发条件 |
| --- | --- |
| 你的晶核被我吃了 | 普通速度达到300%后，再次选择速度强化；开发者500%或更高速度同样能触发 |
| 焕然一新 | 首次花费10金币换肤 |
| LET'S PLAY AGAIN | 使用主页重置按钮，清空金币与原有成就后获得 |
| 秒天秒地 | 暴击概率先达到100%，随后继续强化暴击伤害倍率，达到 **1000%（10倍）或以上** |
| 残血反杀 | 当前生命值在 **1～10（含10）** 时击杀一个五阶怪物；六阶BOSS不算 |
| 博尔特 | 一局内连续3次选择速度强化，期间选择其他强化会中断连续计数 |
| 风浪越大鱼越贵 | 首次进入数学大战特殊模式 |

“秒天秒地”解锁后，子弹和拖尾变为黑色，配有灰色描边方便辨认。成就保存后，后续游戏也保留该外观；清除该成就后恢复普通子弹。

集齐当前全部7个成就后，回到主页会出现鸡头蛇身的角色，提示开发者暗码，约8秒后消失。重新进入主页可再次看到。由于重置会清空成就，若要集齐，可以先取得重置成就，再收集其余六个。

## 开发者模式

这是公开的游戏调试功能，不是账号权限系统。无需输入命令或密码：

1. 回到主页，确保焦点不在输入框中。
2. 依次按方向键 **上、上、下、下、左、右、左、右、上、下**。
3. 即 **↑↑↓↓←→←→↑↓**。这是10次按键，不是需要输入的中文文字。
4. 主页显示“开发者模式已开启”，再选择游戏模式开始。

| 属性 | 开发者模式效果 |
| --- | --- |
| 每次攻击伤害 | 固定 `2^30 = 1,073,741,824`，近战与子弹一致 |
| 移动速度 | 基础速度500%，即600 |
| 生命 | 无限，不受敌人攻击扣血 |
| 晶核掉落 | 仅几何模式：普通掉落数量的2000%，即20倍；数学模式不掉落晶核 |

金币仍遵循50%概率掉1枚规则，不随晶核加成翻倍。速度强化仍可点击并获得相关成就，但不会覆盖开发者速度。

游戏中按 **O** 返回主页，开发者状态仍保留；在主页按 **K** 退出开发者模式。**普通模式按O不会返回主页，游戏中按K也不会退出开发者模式。**按键不区分大小写。答题框获得焦点时，O等字符不会触发开发者快捷键，先点击框外再操作。

开发者状态不会保存；刷新页面后恢复普通状态。开发者模式也支持空格暂停攻击、1键暂停游戏。

## 更新与常见问题

### 更新仓库版本

如果本地有改动，先提交或备份，再更新；不要用强制重置覆盖自己的文件。

```bash
git pull --ff-only
pnpm install --frozen-lockfile
pnpm test:monkey
pnpm dev
```

生产环境请在更新后重新构建，再按你的进程托管方式重新启动。

### 端口被占用

改用其他端口，或确认占用者是自己的旧服务后停止它。启动脚本不会自动杀死占用端口的进程。

### Node版本过旧 / 无法启动

检查 `node --version`，必须至少20.9。系统可能同时装了多个Node，检查实际命令对应的路径。换版本后重新安装依赖。

### frozen lockfile / overrides不匹配

先检查 `pnpm --version` 是否为9.0.0。使用项目声明版本再安装，不要默认使用系统中不兼容的新版包管理器。

### Windows提示bash、ss或grep不存在

新版本的 `pnpm dev/build/start` 直接运行Node脚本，不需要这些命令。先更新完整项目，确认不是运行旧版脚本。

### 构建后服务找不到构建结果

先运行 `pnpm build`；如果设置过 `YBH_DIST_DIR`，启动时使用完全相同的值。不要在不同输出目录之间混用。

### 访问不到 / 页面打不开

确认终端服务没有退出、端口正确，地址使用HTTP协议。本机服务默认5001；跨设备访问需要使用主机局域网地址，并允许相应防火墙访问。HTTPS域名应由部署环境处理。

### 金币或成就“丢失”

检查是否切换了浏览器、域名、端口、隐私窗口，或清理过网站数据。源代码更新通常不会清理同来源存档；主页重置按钮会明确清空金币和成就。

### 暂停、移动或开发者按键没有响应

先点游戏画面，确认焦点不在数学输入框。数学输入框里数字1用于答题；升级选择本身也暂停游戏。长按按键的自动重复不触发多次暂停切换或暗码激活。

### 移动设备

当前主要为桌面键盘设计，草稿纸支持触摸，但没有完整的虚拟移动和快捷键面板。移动端不保证能够完成所有操作。

### ZIP里为什么没有node_modules？

源码ZIP包含应用源码、静态资源、锁文件、说明、测试和配置，不含`.git`、`node_modules`、`.next`、日志或本地秘密配置。这些是机器相关产物，解压后按快速启动步骤重新安装和运行。
