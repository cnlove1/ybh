# 发布前验证（2026-10-25）

## 当前规则

- 暴击概率100%上限，满级后每次暴击精通增加5个百分点伤害倍率。
- “秒天秒地”：概率100%且暴击伤害倍率1000%（10倍）或更高，图鉴已明确该流程；伤害倍率未设硬上限。
- 怪物强化最高1000%（10倍），怪物速度独立限制为原始200%。
- 本次同步保留远端“博尔特”“风浪越大鱼越贵”、怪物速度/击退平衡和屏幕外生成更新。
- 与旧远端规则冲突时采用本次对话指定规则：金币50%概率掉1枚、换肤10金币、开发者500%速度/无限生命/固定2³⁰伤害/20倍晶核、重置后获得重新开始成就。

## 已验证

- 38组自动化测试全部通过，包含4000次固定种子随机操作和4000帧模拟；成就全组合覆盖随图鉴扩展至128种。
- 类型检查、外部地址检查、平台API清单检查、脚本语法检查通过。
- Next.js生产构建通过。
- 独立输出目录`.next-release`、端口5002验证生产启动，首页和`/api/watermark`均返回HTTP 200。
- 启动入口已改为跨平台Node脚本；已有Bash入口仍可调用同一脚本，不再依赖ss/grep或强制结束占用端口的其他进程。
- 添加缺失的平台API清单，修正外部地址检查器中项目根目录初始化顺序。

早期测试报告中的成就数量与平衡上限反映当时版本；最新规则以README、源码和本记录为准。

模拟hooks/Canvas的测试不能代替所有真实浏览器和移动设备的长期运行测试。未修改用户浏览器既有存档。
